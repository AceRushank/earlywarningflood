       - 3RIMG_L2B_HEM: "Active" (Coverage: 2016-10-11 to present)
     Both satellites covered the 2022 target window.

2. PRODUCT SPECIFICATIONS [VERIFIED]:
   - Temporal Resolution: Half-hourly (30 minutes).
   - Spatial Resolution: 4 km curvilinear geostationary grid.
   - Spatial Extent: 30°E to 130°E, 50°N to 50°S (Full Indian Region, fully covers Vishnupuri / Godavari).
   - Units: mm/h (millimeters per hour rain rate).
   - Format: HDF5 (.h5), dataset /HEM, 2D float arrays with scale factor 0.01 and fill value -999.0.
   - Compatibility: Reusable with existing scripts/extract_mosdac_hdf.py logic with minor adaptation for 3DIMG/3RIMG prefix.

3. ORDERING & DATA ACCESS PROCESS [VERIFIED]:
   - Process: MOSDAC does not provide direct instant REST API downloads for historical full archives.
   - Workflow:
       Step 1: User logs into MOSDAC Web Portal (mosdac.gov.in/catalog/).
       Step 2: Searches Mission "INSAT-3D" (or "INSAT-3DR") and Product "3DIMG_L2B_HEM".
       Step 3: Selects date range (2022-05-07 to 2022-11-17), adds to cart, and submits order.
       Step 4: MOSDAC backend processes the batch request asynchronously and assigns a Request ID.
       Step 5: Files are staged into the user's SFTP directory (download.mosdac.gov.in:22) under /order.
       Step 6: Existing script (scripts/download_mosdac_hdf.py) downloads staged files via SFTP.
   - Limitations: Turnaround time for staging ~9,300 files typically ranges from 24 to 72 hours; requires MOSDAC admin quota approval for large volumes.
